  1. PENTDECK_BUY_BOT_TOKEN=<the bot buyers message>
  2. pentdeck seller whoami          (message your bot once first)
  3. PENTDECK_BUY_CHAT_ID=<your chat id from that list>
  4. pentdeck seller run
