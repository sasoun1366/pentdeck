## pentdeck 0.1.1 — the seller bot, and Windows executables

Two things were missing before this tool could be sold: something to take the order, and
something a customer without Python can run. Both are here.

### Selling it

```bash
pentdeck license wallet T…        # the address buyers pay to, stored once
pentdeck seller run               # the order bot
```

A buyer sends the request the app wrote. The bot answers with the wallet address, the
exact amount and an order code, and tells you. The buyer sends a transaction id. You check
the wallet — ten seconds — and one message finishes the sale:

```
/confirm PD-7K3Q      → the signed token goes to the buyer's chat
/orders  /issue  /cancel  /stats
```

**Your confirmation is the only thing that issues a licence.** A bot cannot verify a TRC20
transfer without a blockchain API key, and trusting the buyer's word would either give the
tool away or annoy someone who paid. So the machine keeps the books and you do the
ten-second check.

Only your own chat may run those commands; a buyer can create an order, report a payment
and ask questions, and can never touch anyone else's order. The **Orders** page in the
dashboard does the same thing with buttons, through the same code path.

Want to see it before wiring a bot? `pentdeck seller demo` runs the whole journey on your
machine — no token, no chat id, no money, nothing sent anywhere.

### Windows, without Python

| download | what it is |
| --- | --- |
| `pentdeck-0.1.1-windows-desktop.exe` | the dashboard: double-click and it opens (36.6 MB) |
| `pentdeck-0.1.1-windows-cli.exe` | the same tool on the command line (9.3 MB) |

One file, no installer, no Python. Licences verify offline — nothing is sent anywhere.

### Also in this release

* the desktop dashboard (`pentdeck gui`): overview, targets, a scan with a live log and a
  stop button, findings with the evidence and a copy-the-fix button, reports, orders, licence
* `pentdeck seller whoami` — finds your own chat id for the setup
* a Windows-only crash in the TLS reader, found by this pipeline's own Windows run:
  WinError 10053 escaped as an `OSError` and could kill a scan on one port
* 154 tests, all offline — the suite starts its own HTTP, TLS and banner servers, drives
  the real window offscreen, and runs a whole buying journey without a network

`docs/example-report.html` shows what the client receives. Full notes in the README.
